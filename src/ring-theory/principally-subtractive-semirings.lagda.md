## Idea

We say that a [semiring](ring-theory.semirings.md) `R` is {{#concept "principally subtractive" Disambiguation="semiring" Agda=is-subtractive-Semiring}} if for every element `a : R`, the [ideal `⟨a⟩` generated by the element `a`](ring-theory.ideals-generated-by-elements-semirings.md) is a [subtractive ideal](ring-theory.subtractive-ideals-semirings.md). In other words, given

```text
  x + y ＝ z
```

in `R`, if `x` and `z` can be written as [linear combinations](ring-theory.linear-combinations-of-elements-semirings.md), then so can `y`.

**Note.** We have not found this concept in the literature.

## Definitions

### The predicate of being a principally subtractive semiring

```agda
module _
  {l1 : Level} (R : Semiring l1)
  where

  is-principally-subtractive-Semiring :
    UU l1
  is-principally-subtractive-Semiring =
    (x : type-Semiring R) →
    is-subtractive-ideal-Semiring R (ideal-element-Semiring R x)
```
