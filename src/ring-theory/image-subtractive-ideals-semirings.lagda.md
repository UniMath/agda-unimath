## Idea

The {{#concept "image subtractive ideal" Agda=im-subtractive-ideal-Semiring}}
of a [subtractive ideal](ring-theory.subtractive-ideals-semirings.md) `I ⊆ R` under a [homomorphism](ring-theory.homomorphisms-semirings.md) `f : R → S` between [semirings](ring-theory.semirings.md) `R` and `S` is the [subtractive ideal generated by](ring-theory.subtractive-ideals-generated-by-families-of-elements.md) the values of `f` on `I`. In other words, the subtractive ideal `f I` is the least [subtractive ideal](ring-theory.subtractive-ideals-semirings.md) containing the element `f x` for each `x ∈ I`. Note that the [image](foundation.images.md) of the underlying map of `f` is the [image nonunital subsemiring](ring-theory.images-nonunital-subsemirings.md), which is not necessarily closed under multiplication by an arbitrary element in `S`. For this reason, we will use the noun phrase "image subtractive ideal" rather than the "image of the subtractive ideal".

Since the image subtractive ideal of a subtractive ideal satisfies the following adjoint relation

```text
  (im f I ⊆ J) ↔ (I ⊆ J ∘ f)
```

it follows that we obtain a
[Galois connection](order-theory.galois-connections.md).

## Definitions

### The universal property of the image subtractive ideal

```agda
module _
  {l1 l2 l3 l4 : Level} (R : Semiring l1) (S : Semiring l2)
  (f : hom-Semiring R S)
  (I : subtractive-ideal-Semiring l3 R) (K : subtractive-ideal-Semiring l4 S)
  where

  is-image-subtractive-ideal-Semiring : UUω
  is-image-subtractive-ideal-Semiring =
    {l : Level} (J : subtractive-ideal-Semiring l S) →
    leq-subtractive-ideal-Semiring S K J ↔
    leq-subtractive-ideal-Semiring R I
      ( pullback-subtractive-ideal-Semiring R S f J)
```

## Properties

### The image subtractive ideal of the subtractive ideal `⟨x⟩` generated by a family of elements `x` under a semiring homomorphism `f` is the subtractive ideal `⟨f ∘ x⟩` generated by the family of elements `f ∘ x`

There are three ways to state this fact:

1. The image subtractive ideal `⟨x⟩` under the semiring homomorphism `f` has the same
   elements as the subtractive ideal `⟨f ∘ x⟩`.
2. The subtractive ideal `⟨f ∘ x⟩` satisfies the universal property of the image subtractive ideal ideal of `⟨x⟩` under the semiring homomorphism `f`.
3. The image subtractive ideal `⟨x⟩` under the semiring homomorphism `f` satisfies
   the universal property of the subtractive ideal generated by the family of elements
   `f ∘ x`.

```agda
module _
  {l1 l2 l3 : Level}
  (R : Semiring l1) (S : Semiring l2) (f : hom-Semiring R S)
  {I : UU l3} (x : I → type-Semiring R)
  where

  forward-inclusion-image-subtractive-ideal-family-of-elements-Semiring :
    leq-subtractive-ideal-Semiring S
      ( im-subtractive-ideal-Semiring R S f
        ( subtractive-ideal-family-of-elements-Semiring R x))
      ( subtractive-ideal-family-of-elements-Semiring S
        ( map-hom-Semiring R S f ∘ x))
  forward-inclusion-image-subtractive-ideal-family-of-elements-Semiring =
    leq-im-subtractive-ideal-Semiring R S f
      ( subtractive-ideal-family-of-elements-Semiring R x)
      ( subtractive-ideal-family-of-elements-Semiring S
        ( map-hom-Semiring R S f ∘ x))
      ( leq-subtractive-closure-ideal-Semiring R
        ( ideal-family-of-elements-Semiring R x)
        ( pullback-subtractive-ideal-Semiring R S f
          ( subtractive-ideal-family-of-elements-Semiring S
            ( map-hom-Semiring R S f ∘ x)))
        ( leq-ideal-family-of-elements-Semiring R x
          ( ideal-pullback-subtractive-ideal-Semiring R S f
            ( subtractive-ideal-family-of-elements-Semiring S
              ( map-hom-Semiring R S f ∘ x)))
          ( contains-elements-subtractive-ideal-family-of-elements-Semiring S
              ( map-hom-Semiring R S f ∘ x))))

  backward-inclusion-image-subtractive-ideal-family-of-elements-Semiring :
    leq-subtractive-ideal-Semiring S
      ( subtractive-ideal-family-of-elements-Semiring S
        ( map-hom-Semiring R S f ∘ x))
      ( im-subtractive-ideal-Semiring R S f
        ( subtractive-ideal-family-of-elements-Semiring R x))
  backward-inclusion-image-subtractive-ideal-family-of-elements-Semiring =
    leq-subtractive-ideal-family-of-elements-Semiring S
      ( map-hom-Semiring R S f ∘ x)
      ( im-subtractive-ideal-Semiring R S f
        ( subtractive-ideal-family-of-elements-Semiring R x))
      ( contains-elements-im-subtractive-ideal-Semiring R S f
          ( subtractive-ideal-family-of-elements-Semiring R x) ∘ 
        contains-elements-subtractive-ideal-family-of-elements-Semiring R x)

  compute-image-subtractive-ideal-family-of-elements-Semiring :
    has-same-elements-subtractive-ideal-Semiring S
      ( im-subtractive-ideal-Semiring R S f
        ( subtractive-ideal-family-of-elements-Semiring R x))
      ( subtractive-ideal-family-of-elements-Semiring S
        ( map-hom-Semiring R S f ∘ x))
  pr1 (compute-image-subtractive-ideal-family-of-elements-Semiring s) =
    forward-inclusion-image-subtractive-ideal-family-of-elements-Semiring s
  pr2 (compute-image-subtractive-ideal-family-of-elements-Semiring s) =
    backward-inclusion-image-subtractive-ideal-family-of-elements-Semiring s

  is-image-subtractive-ideal-family-of-elements-Semiring :
    is-image-subtractive-ideal-Semiring R S f
      ( subtractive-ideal-family-of-elements-Semiring R x)
      ( subtractive-ideal-family-of-elements-Semiring S
        ( map-hom-Semiring R S f ∘ x))
  is-image-subtractive-ideal-family-of-elements-Semiring =
    is-image-has-same-elements-subtractive-ideal-Semiring R S f
      ( subtractive-ideal-family-of-elements-Semiring R x)
      ( subtractive-ideal-family-of-elements-Semiring S
        ( map-hom-Semiring R S f ∘ x))
      ( compute-image-subtractive-ideal-family-of-elements-Semiring)

  is-subtractive-ideal-generated-by-family-of-elements-image-subtractive-ideal-family-of-elements-Semiring :
    is-subtractive-ideal-generated-by-family-of-elements-Semiring S
      ( map-hom-Semiring R S f ∘ x)
      ( im-subtractive-ideal-Semiring R S f
        ( subtractive-ideal-family-of-elements-Semiring R x))
  is-subtractive-ideal-generated-by-family-of-elements-image-subtractive-ideal-family-of-elements-Semiring
    =
    is-subtractive-ideal-generated-by-family-of-elements-has-same-elements-Semiring
      ( S)
      ( map-hom-Semiring R S f ∘ x)
      ( im-subtractive-ideal-Semiring R S f
        ( subtractive-ideal-family-of-elements-Semiring R x))
      ( inv-iff ∘ compute-image-subtractive-ideal-family-of-elements-Semiring)
```

### The image subtractive ideal of the subtractive ideal `⟨x⟩` generated by an element `x` under a semiring homomorphism `f` is the subtractive ideal `⟨f(x)⟩` generated by the element `f(x)`

As before, there are three ways to state this fact:

1. The image subtractive ideal of `⟨x⟩` under the semiring homomorphism `f` has the same
   elements as the subtractive ideal `⟨f(x)⟩`.
2. The subtractive ideal `⟨f(x)⟩` satisfies the universal property of the image
   subtractive ideal of `⟨x⟩` under the semiring homomorphism `f`.
3. The image subtractive ideal of `⟨x⟩` under the semiring homomorphism `f` satisfies
   the universal property of the subtractive ideal generated by the element `f(x)`.

      ( subtractive-ideal-element-Semiring S (map-hom-Semiring R S f x))

    leq-im-subtractive-ideal-Semiring R S f
